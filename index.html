    📌 简介

    AI 智能错题本帮你自动归类错题、智能复习、个性化推荐。纯前端可用，接入后端更完整。

    🚀 快速开始

    1. 点击「录入」→ 选学段 / 年级 / 学科 → 填题 → 「智能预分析」→ 保存
    2. 在「错题集」查看，自动按学科 / 错误类型分组
    3. 在「复习」完成到期队列的自评
    4. 在「数据看板」看趋势

    🎓 学段与考试

    支持从小学到大学的完整学段，加上 10 类社会性考试：考研、公务员、教师资格、法律职业资格、注册会计师、执业医师、雅思、托福、英语四六级、计算机等级。

    社会性考试下，「年级」槽位即考试名称，学科随考试变化（如考研的政治/英语/数学，公务员的行测/申论）。

    🤖 AI 与大模型

    点击顶栏 「⚙ 设置」，填写 API Key / Base URL / Model 即可启用大模型（配置保存在后端 data/config.json）。保存时会自动校验连通性。

    也可以在启动后端时设置环境变量启用：

    LLM_API_KEY=sk-xxx LLM_BASE_URL=https://api.openai.com/v1/chat/completions LLM_MODEL=gpt-4o-mini node server.js

    未配置时自动回退本地规则引擎，仍然可用。顶栏圆点（绿=已接入 / 红=本地规则）可快速判断当前状态。

    🔌 功能所需的外部 API

    本应用的 AI 能力依赖以下两类外部 API，在「⚙ 设置」中填写即可接入（配置存于后端 data/config.json）：

    1. 大模型 API（智能分析 / 变体题 / AI 批改 / AI 答疑）

    • 接口：POST {Base URL}（OpenAI 兼容的 /chat/completions）
    • 鉴权：Authorization: Bearer {API Key}
    • 请求体：{ "model": "...", "messages": [{"role":"user","content":"..."}], "temperature": 0.2 }
    • 适用厂商：OpenAI / Azure OpenAI / 通义千问 / 智谱 GLM / DeepSeek 等任意兼容端点

    2. OCR API（拍照 / 粘贴图片识别题目）

    • 方案 A · 跟随大模型（OpenAI 兼容视觉）：复用上面的 LLM 配置，把图片作为 image_url 内容块发送，模型返回识别文字。需模型支持视觉（如 gpt-4o、qwen-vl、glm-4v、deepseek-vl）。
    • 方案 B · 百度智能云 OCR：POST https://aip.baidubce.com/rest/2.0/ocr/v1/accurate_basic?access_token=TOKEN，需 API Key + Secret Key（后端自动用密钥换取 access_token）。
    后端内置本地规则兜底：未配置外部 API 时，分析 / 变体 / 批改 / 答疑仍可用，只是不走真实大模型。

    🌐 浏览器直连模式（无后端也能用 AI）

    当应用以纯静态方式部署（CloudStudio、GitHub Pages 等，没有 Node 后端）时，「⚙ 设置」里保存的 LLM 配置会写入浏览器 localStorage，AI 功能由浏览器直接调用厂商接口，无需后端：

    • 智能分析 / 变体题 / AI 批改：浏览器直连 /chat/completions 并解析 JSON。
    • AI 答疑：浏览器直连并逐字流式输出。
    • OCR：仅「跟随大模型（视觉）」厂商可直连；百度 OCR 需服务端签名，静态部署下不可用（请运行后端）。
    提示：配置保存后即使没有后端也能生效（顶栏显示绿点 + 模型名即代表已接入）。
    CORS 限制：部分厂商（如 OpenAI 官方接口）默认不允许浏览器跨域调用，直连会失败。若遇 CORS 错误，请：① 改用允许 CORS 的兼容端点或代理；或 ② 在本机运行 node server.js 由后端转发请求。
    想让链接「打开即用、无需手动设置」？在部署目录放一个 config.js（设置 window.__APP_CONFIG__ 填入 Base URL/Model），应用启动时会自动读取并启用。模板见 config.example.js。
    🔐 密钥安全：纯静态部署（GitHub Pages / CloudStudio）若把 API Key 写进 config.js，公开站点会泄露密钥。推荐做法——用 Serverless 代理（仓库里的 api/llm.js 适用于 Vercel，netlify/functions/llm.js 适用于 Netlify）：密钥只放在函数环境变量，前端 config.js 只填函数地址、Key 留空，由函数注入密钥转发。这样前端零密钥、链接打开即用。

    🔁 间隔复习

    采用 Leitner 5 盒系统：

    • L1：1 天后复习
    • L2：3 天后复习
    • L3：7 天后复习
    • L4：16 天后复习
    • L5：30 天后复习 → 已掌握

    「记住了」升级一盒，「还不会」回到 L1。也可以用录入时的 5 色评分按钮预估掌握程度。

    🔍 向量库 / 相似题

    后端用中文 bigram TF-IDF + 余弦相似度做向量库。添加错题时相似度 ≥ 0.82 自动标 duplicateOf。详情弹窗会显示相似错题。

    ⚙️ 部署与配置

    # 前端
python -m http.server 8000
# 后端（默认 3000）
node server.js
# 启用 OCR
（OCR_API_KEY=xxx node server.js）

    ❓ FAQ

    后端连不上怎么办？

    前端会自动回退 localStorage，核心功能仍可用。

    数据会丢吗？

    localStorage 镜像了一份；也可以用「导出」备份 JSON。
